
# Parsing food recipes.

* Parser for [Delish](https://www.delish.com/).
* This parser takes the user request and the X number of recipes the user wants to get, returns the list of recipes that have been saved and offers to choose which recipe the user wants to save in a .docx file. Then it returns that .docx file.
